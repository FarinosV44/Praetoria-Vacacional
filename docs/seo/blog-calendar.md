# Blog editorial calendar (issue #94)

The blog exists to capture "planning-stage" local searches and route them to a
direct booking. Every post targets **one property** (`ctaPropertySlug` in the
admin) so the contextual CTA, the top strip and the Booking Bar all preselect it.

## Rules

- One post = one search intent + one clear next action (see the CTA rendered by
  `ctaForPost`).
- Local clusters only — Llastra / El Perelló / Albufera / Sueca / Cullera for
  Valencia; Camarena de la Sierra / Javalambre / Gúdar-Javalambre for the sierra.
- No thin "top 10" filler. Each post must answer a real question a guest asks
  before booking.
- Publish on a real cadence (2–3 / month). Update dated posts each season rather
  than spawning near-duplicates.
- Never cannibalise `/guias/*` (evergreen hubs) — the blog is dated/actualidad.
